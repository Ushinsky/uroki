Числовые промежутки

Алгебра, § 4, пункт 11. Разберём рисунки на координатной прямой и научимся записывать их неравенствами.

Самое главное

  1. Выделенная часть прямой показывает подходящие числа.
  2. Закрашенная точка означает «число входит»; пустой кружок — «не входит».
  3. Читаем границы слева направо и выбираем знаки неравенства.
Шаг 1

Что показывает промежуток

На координатной прямой числа растут слева направо. Если a < b, то точка a расположена левее b. Число x между ними больше a и меньше b.

Пустой кружок — граница не входит: знак < или >.
Закрашенная точка — граница входит: знак ≤ или ≥.

Например, для чисел между 1 и 4: 1 < x < 4. Число 2 подходит, а 1 и 4 не входят.

Шаг 2

Отрезок, интервал и полуинтервалы

Пусть a < b. Различие — входят ли концы.

Отрезок: a ≤ x ≤ b; запись [a; b]. Оба конца входят.
Интервал: a < x < b; запись (a; b). Оба конца не входят.
Полуинтервалы: a ≤ x < b записывают [a; b); a < x ≤ b записывают (a; b]. Входит только конец у квадратной скобки.

Отрезки, интервалы и полуинтервалы называют числовыми промежутками.

Шаг 3

Когда промежуток продолжается в одну сторону

Вправо от числа a расположены числа больше него. Влево — меньше него.

x ≥ a — луч вправо, точка a входит; x > a — точка не входит. В учебнике они названы соответственно замкнутым и открытым лучом.

Для луча влево: x ≤ a, если точка входит, и x < a, если не входит.

Шаг 4

Расстояние между двумя точками

Это тоже часть пункта 11. Расстояние от точки с координатой x до нуля равно |x|. Для точек A(a) и B(b) учебник даёт формулу:

Расстояние: AB = |b − a|. Модуль нужен, чтобы расстояние оставалось неотрицательным.
Почему получается эта формула

Пусть A(a) левее B(b), то есть a < b. Учебник рассматривает три случая:

  1. Обе точки правее нуля: AB = OB − OA = b − a.
  2. Точки по разные стороны от нуля: AB = OA + OB = −a + b = b − a.
  3. Обе точки левее нуля: AB = OA − OB = −a − (−b) = b − a.

Если A правее B, расстояние равно a − b. Поэтому в обоих случаях его можно записать как |b − a|.

Пример 1. Точки по разные стороны от нуля

  1. Находим разность координат: 3 − (−2) = 5.
  2. Берём модуль: |5| = 5.

Ответ: 5

Пример 2. Обе точки слева от нуля

  1. Находим разность: −2 − (−5) = 3.
  2. Берём модуль: |3| = 3.

Ответ: 3

Шаг 5

Как выполнить задание вроде № 248

Нужно записать неравенство по выделенному промежутку. Сначала смотри, где выделение; затем проверь каждую точку на его границе.

Пример 1. Две границы

  1. Слева −4. Пустой кружок: −4 не входит. Значит, −4 < x.
  2. Справа 3. Закрашенная точка: 3 входит. Значит, x ≤ 3.
  3. Соединяем: сначала левое число, затем x, затем правое число.

Ответ: −4 < x ≤ 3

Пример 2. Луч влево

  1. Выделены числа левее 2: они меньше двух.
  2. Кружок пустой, поэтому само число 2 не входит.

Ответ: x < 2

Не перепутай: в записи −4 < x ≤ 3 знак возле −4 относится к левой точке, знак возле 3 — к правой.
