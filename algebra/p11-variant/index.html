Числовые промежутки

Алгебра 7, §4, пункт 11. Цель урока: посмотреть на рисунок с прямой и записать его одним неравенством. Именно это нужно в №248.

1Что такое «выделенная часть прямой»

На координатной прямой числа растут слева направо: правое число больше, левое меньше.

Если закрасить на прямой кусочек, мы выделим сразу много чисел: все, которые на нём стоят.

Здесь выделены все числа между −3 и 2. Буквой x мы называем любое одно число из выделенной части: например 0, или 1, или −2,5.

Любое такое x правее −3 и левее 2. Значит, оно больше −3 и меньше 2. Записываем: −3 < x < 2.

Проще говоря: запись −3 < x < 2 — это тот же рисунок, только написанный цифрами и знаками. Читается так: «x больше −3 и меньше 2». В учебнике вместо чисел стоят буквы: a < x < b. Это то же самое: a — левое число, b — правое.

2Кружки на концах: входит число или нет

Сами крайние числа (−3 и 2) тоже надо как-то оценить: они входят в выделенную часть или нет? Это показывает кружок.

Светлый (пустой) кружокчисло не входит
знак < или > (без чёрточки)
Закрашенный кружокчисло входит
знак ≤ или ≥ (с чёрточкой)
Запомни: чёрточка под знаком значит «или равно». Когда число само входит, оно «равно допустимому» — ставим чёрточку. Когда не входит — чёрточки нет.

3Как называются промежутки (из учебника)

Все выделенные части называют числовыми промежутками. Название зависит только от одного: входят ли крайние числа. Возьмём конкретные числа 1 и 4 и посмотрим на все четыре случая. Рисунки похожи — различаются только кружки.

Отрезок
1 входит, 4 входит
Оба кружка закрашены
1 ≤ x ≤ 4, запись [1; 4]
Интервал
1 не входит, 4 не входит
Оба кружка пустые
1 < x < 4, запись (1; 4)
Полуинтервал
1 входит, 4 не входит
Один закрашен, другой пустой
1 ≤ x < 4, запись [1; 4)
Полуинтервал
1 не входит, 4 входит
Тоже один закрашен, другой пустой
1 < x ≤ 4, запись (1; 4]
Как не путать названия: считай закрашенные кружки.
Два закрашены — отрезок. Ни одного — интервал. Один — полуинтервал («полу» — половина концов входит).

Если конец только один — это луч

У луча выделение уходит в бесконечность (стрелка), поэтому в записи только одно число. Название зависит от кружка: закрашен — замкнутый луч, пустой — открытый.

Замкнутый луч вправо
x ≥ 2: число 2 входит
Открытый луч вправо
x > 2: число 2 не входит
Замкнутый луч влево
x ≤ 2: число 2 входит
Открытый луч влево
x < 2: число 2 не входит

4Три вопроса к любому рисунку

  1. Куда идёт выделение? Между двумя числами или в одну сторону?
  2. Какой кружок на каждом конце? Пустой — знак без чёрточки, закрашенный — с чёрточкой.
  3. Пишем слева направо, как на рисунке: левое число, знак, x, знак, правое число.

Для луча: выделение идёт влево — числа меньше границы: x < число. Идёт вправо — числа больше: x > число.

Частая ошибка: писать большее число слева. Записывай в том же порядке, как числа стоят на прямой: меньшее число — слева.

5Разбираем пример (похож на №248 а и б)

Пример А. Задайте неравенством промежуток

  1. Куда идёт выделение? Между −3 и 2. Значит, x зажат между ними: −3 … x … 2.
  2. Левый конец −3. Кружок пустой: число не входит. Ставим < без чёрточки: −3 < x.
  3. Правый конец 2. Кружок закрашен: число входит. Ставим ≤ с чёрточкой: x ≤ 2.
  4. Склеиваем в одно: −3 < x ≤ 2

Проверка. Возьмём числа:

числона рисункев записи
0выделено−3 < 0 ≤ 2 — верно ✓
2закрашено2 ≤ 2 — верно ✓
−3пустой кружок−3 < −3 — неверно ✓ (и правда не входит)

Пример Б. Луч

  1. Куда идёт выделение? Влево от 4 — это числа меньше 4. Граница одна.
  2. Кружок у 4 пустой: число 4 не входит — знак без чёрточки.
  3. Ответ: x < 4

Проверка: 3 выделено и 3 < 4 верно ✓. Число 4 не выделено и 4 < 4 неверно ✓.

Ещё два быстрых образца

Оба закрашены → обе чёрточки:
−1 ≤ x ≤ 6
Оба пустые → ни одной чёрточки:
0 < x < 5

6Расстояние между точками (вторая часть пункта)

От точки с координатой x до нуля расстояние равно модулю: |x|. Например, от −2 до 0 — две единицы, поэтому |−2| = 2.

Для двух точек A(a) и B(b) в учебнике доказана формула: AB = |b − a|. Читают так: расстояние между двумя точками координатной прямой равно модулю разности их координат.

Решение: 3 − (−2) = 5, |5| = 5. Ответ: 5. Если точки в другом порядке, получится −5, а модуль уберёт минус: расстояние не бывает отрицательным.

Учебник проверяет формулу в трёх случаях (обе точки правее нуля, по разные стороны, обе левее) — везде получается b − a. Для №248 эта часть не нужна: она пригодится в №251–252.
