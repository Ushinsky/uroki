Линейное уравнение с одной переменной

Алгебра, п. 8. Классная работа 12 октября. Страницы в клетку — это то, что записано у вас в тетради.

Весь урок в трёх фразах

  1. Линейное уравнение — самое простое: «число · x = число», например 5x = −60.
  2. Чтобы найти x, делим число справа на число перед x.
  3. Если уравнение сложнее, сначала переносим: иксы — влево, числа — вправо. И оно превращается в простое.
Шаг 1

Что такое линейное уравнение

Определение. Уравнение вида ax = b, где x — переменная, a и b — некоторые числа, называется линейным уравнением с одной переменной.

Буквы a и b здесь — просто «места для чисел»:

5x = −60a = 5, b = −60
0,7x = 0a = 0,7, b = 0
−0,2x = −1a = −0,2, b = −1

a — число, на которое умножен x. b — число по другую сторону от «=».

Как его решать — запись в тетради

запись в тетради
ax = bx умножили на a и получили b
x = baзначит, x = b, делённое на a (черта дроби — это деление)
Почему делим? Представь: 5 одинаковых коробок весят 60 кг. Сколько весит одна? Делим: 60 : 5 = 12. Уравнение 5x = 60 — то же самое.

Шаг 3

Если перед x дробь — № 146

Главный секрет. Разделить на дробь — то же самое, что умножить на перевёрнутую дробь.
: 13  →  · 31 = · 3      : 23  →  · 32

Проверь на понятном: сколько третей в 12 пиццах? В каждой пицце 3 трети, значит 12·3 = 36. Поэтому 12 : 13 = 12 · 3.

запись в тетради · № 146 а)
а) 13x = 12a = 1/3, b = 12
x = 12 : 13как всегда: b делим на a
x = 12 · 3делить на 1/3 = умножить на перевёрнутую 3/1, то есть на 3
x = 3612·3 = 36
Ответ: x = 36проверка: треть от 36 — это 12 ✓
запись в тетради · № 146 б)
б) 23y = 9тут переменная обозначена y — решаем так же

y = 9 · 32делить на 2/3 = умножить на перевёрнутую 3/2
y = 13,59·3 = 27, 27 : 2 = 13,5
Ответ: y = 13,5

Если есть «лишнее» число — № 147

В 5x − 150 = 0 мешает число −150 рядом с иксом. Сначала переносим его вправо, меняя знак (это вы проходили в п. 7). Получается простое уравнение, как в № 145.

x = 30
Ответ: x = 30проверка: 5·30 − 150 = 0 ✓

Шаг 6

Сколько корней у линейного уравнения

Почти всегда — один. Но если перед иксом окажется 0, разделить нельзя (на ноль не делят). Тогда два особых случая:

a ≠ 0 — один корень5x = −60
x = −12
0·x = 7 — нет корнейЛюбое число, умноженное на 0, даёт 0, а не 7. Ни один x не подходит.
0·x = 0 — любое числоЛюбое число, умноженное на 0, даёт 0. Подходит каждый x.
Пример из учебника: как получается 0·x
2x + 5 = 2(x + 6)исходное уравнение
2x + 5 = 2x + 12раскрыли скобки: 2·x + 2·6
2x − 2x = 12 − 5иксы — влево, числа — вправо
0x = 7иксы сократились до нуля — значит, корней нет
